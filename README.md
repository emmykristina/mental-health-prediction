This project focuses on predicting the risk of depression and mental health issues using an Artificial Neural Network (ANN).

The model is trained on factors related to lifestyle, academic pressure, work pressure, sleep habits, and personal wellbeing in order to identify patterns associated with mental health risks.

Business Value

Using AI-based prediction models within healthcare and digital health platforms can help organizations:

identify individuals at higher risk earlier
support preventive mental healthcare
improve decision support for healthcare professionals
enable faster access to support and resources
reduce long-term healthcare costs
improve overall patient wellbeing

This project demonstrates how deep learning can be applied to mental health prediction and healthcare analytics.
